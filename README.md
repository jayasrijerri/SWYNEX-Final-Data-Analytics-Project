# SWYNEX Final Data Analytics Project

## Project Overview

This final project combines data cleaning, exploratory data analysis and interactive dashboard development completed during my Data Analyst Internship with SWYNEX Technologies.

## Problem Statement

The objective is to analyze sales data and identify useful business insights related to categories, regions, sub-categories and monthly sales performance.

## Project Workflow

1. Data cleaning using Microsoft Excel.
2. Exploratory Data Analysis using summary statistics, PivotTables and charts.
3. Interactive dashboard creation using Microsoft Power BI.
4. Business insights and final conclusions.

## Dashboard Features

- Total Sales KPI
- Average Sales KPI
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive filters
- Business-focused visualizations

## Key Insights

- Technology generated the highest sales.
- West region recorded the highest sales.
- Phones was the top-selling sub-category.
- Monthly sales performance was analyzed using Power BI.
